# MifiTech — Websites & Digital Products

A Next.js portfolio and client-acquisition website for MifiTech.

## What is included

- Agency homepage covering services, process, selected software projects and contact enquiries.
- Five shareable industry website concept previews:
  - `/demos/event-planner`
  - `/demos/fashion-boutique`
  - `/demos/restaurant`
  - `/demos/beauty-salon`
  - `/demos/printing`
- Existing project case studies under `/projects/[slug]`.
- Responsive layouts for mobile, tablet and desktop.

All industry demos use fictional sample brands and illustrative content. They are concept previews, not client websites. Replace demo copy, imagery, services and business details when preparing a prospect-specific preview.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Project enquiry forms are configured to deliver through FormSubmit to the MifiTech contact email. FormSubmit may require first-time email activation before delivery is enabled.
